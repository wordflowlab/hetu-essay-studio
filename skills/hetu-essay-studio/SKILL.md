# 散文工坊

先经河图稳定CLI/MCP发现当前安装包、capabilities及本包方法；携带精确WorkRef、management_ref和活动摘要，不新建Codex插件或假定当前作品。

先读已有专业工程、固定来源和意见。固定作品和已有材料 → 保留观察与回忆的声明 → 准备片段和意象 → 比较不同编排 → 按固定意见局部返工 → 复核旧依据 → 阅读本与下一稿候选。作者给出自然语言目标时由Agent准备结构，不要求作者在GUI重复填表；业务不依赖运行窗口。

原始引文和观察只追加；事实观察、记忆、虚构和借用是提交者声明，不是软件认证。片段固定其观察组合摘要，编排固定片段及独立出场次序的组合摘要。同一片段可以多次出场，但每次出场有独立ID和顺序，不按内容去重。改片段后旧编排、意见和备选明确待复核。新建或改变依据时必须匹配当前摘要，沿原基线未改的旧记录允许保持过期；不能用整本保存绕过快照核验。备选应用固定完整片段摘要，保留其他片段原字节，正文采纳另行决定。

方法与完整反例见[工作流程](references/workflows.md)，动作参数见[操作地图](references/operations.md)。保存后回读固定修订与原操作；未知先get_operation，CAS冲突保留原输入，不换键重发。阶段边界用create_handoff保存固定依据、未读范围和下一步。

专业检查不代替文学判断。外发、费用、正文采纳和定稿沿作者确切决定执行；不得扩大作品范围或绕过宿主事务。
