# Skill与机器接续

包内hetu-essay-studio由河图动态发现，不创建Codex插件、独立MCP服务器或客户端工具名。安装和启用后重新读取活动包摘要、capabilities与skills.read；旧能力绑定不得继续使用。业务无需启动桌面。

默认旅程：固定作品和已有材料 → 保留观察与回忆的声明 → 准备片段和意象 → 比较不同编排 → 按固定意见局部返工 → 复核旧依据 → 阅读本与下一稿候选。先读已有工程、固定作品及意见，不新建另一份演示工程替代接续。方法由Skill维护，确定性规则由专业后端执行。

原始引文和观察只追加；事实观察、记忆、虚构和借用是提交者声明，不是软件认证。片段固定其观察组合摘要，编排固定片段及独立出场次序的组合摘要。同一片段可以多次出场，但每次出场有独立ID和顺序，不按内容去重。改片段后旧编排、意见和备选明确待复核。新建或改变依据时必须匹配当前摘要，沿原基线未改的旧记录允许保持过期；不能用整本保存绕过快照核验。备选应用固定完整片段摘要，保留其他片段原字节，正文采纳另行决定。

每阶段保存并回读固定修订，create_handoff记录依据、目标与未解决问题。其他插件根据实际安装能力独立发现，通过固定专业引用组合。未知先回读，正文采纳、定稿、内容外发与费用按作者确切决定执行。

SKILL.md作为精炼方法入口，references/workflows.md提供专业方法与反例，operations.md从正式清单生成。专业清单由本仓库维护，宿主40只导航动态入口。
